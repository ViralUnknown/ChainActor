The error is **not caused by missing your Browserless token**—it is caused by **how the Browserless URL is constructed in `src/main.js**`.

---

### Where the Problem Is Coming From

Look at line 113 of your code:

```log
2026-09-11T23:58:21.192Z browserType.connectOverCDP: Unexpected status 400 when connecting to https://production-sfo.browserless.io/json/version/?token=...
2026-09-11T23:58:21.198Z at /home/myuser/src/main.js:113:30

```

1. **Playwright `connectOverCDP` does an internal HTTP fetch to `/json/version**` when passed an `https://` base URL.
2. When Browserless receives an HTTP `GET /json/version?token=...&stealth=true` request on its SFO production region, it rejects parameters like `&stealth=true` on the standard DevTools HTTP endpoint, returning a **`400 Bad Request`**.
3. Because Playwright got a `400 Bad Request` instead of JSON metadata, the execution crashes.

---

### How to Fix It in `src/main.js`

Go to **`src/main.js` around line 110–113** where `chromium.connectOverCDP(...)` or `browserType.connectOverCDP(...)` is called.

#### Option A: Direct WebSocket connection (Recommended)

Change your connection string so Playwright connects directly via WebSockets (`wss://`) instead of HTTP (`https://`).

```javascript
// Replace whatever endpoint logic you have around line 110 with:
const token = process.env.BROWSERLESS_TOKEN || input.browserlessToken;
const endpoint = `wss://production-sfo.browserless.io/playwright?token=${token}&stealth=true`;

const browser = await chromium.connectOverCDP(endpoint);

```

#### Option B: Clean the HTTP URL

If you are passing the base URL as an input or environment variable, make sure the string passed into `connectOverCDP` uses the `/playwright` route path rather than the root domain:

```javascript
// Correct Browserless Playwright WebSocket path:
const endpoint = `wss://production-sfo.browserless.io/playwright?token=${YOUR_TOKEN}`;

```

### What to put in your Apify Input / Environment Variables

In your Apify Actor input or Envs:

* **Browserless Endpoint / Host**: `wss://production-sfo.browserless.io/playwright` (or `wss://chrome.browserless.io/playwright`)
* **Browserless Token**: `2VF5zeHqJjrhVex...`

Once `src/main.js` uses `wss://.../playwright`, Playwright bypasses the HTTP `/json/version` lookup and establishes the browser connection directly.
